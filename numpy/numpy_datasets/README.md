# 素材說明

所有資料均為本教材自製的虛構練習資料，不代表實際價格、制度或真實學生。

| 檔案 | 結構 | 用途 |
| --- | --- | --- |
| lunch_orders.csv | 3 筆；姓名、餐點、單價（元）、份數 | 第 19 節訂單小計 |
| student_scores.csv | 8 筆；學號、姓名、三科 0–100 分 | 第 20 節完整分析 |

成績科目固定依序為餐飲實作、服務溝通、安全衛生，權重為 0.5、0.3、0.2。學號是唯一識別碼。空白是未登錄，`待補` 是刻意放入的非數字，120 是刻意放入的超範圍值。S004 同時有兩格需查核。安全衛生整科為 100，用來練習零標準差；S001、S008 同分，用來練習競賽排名。

來源檔維持 UTF-8、逗號分隔。程式不修改來源檔；匯出 CSV 使用 UTF-8 BOM，便於一般試算表軟體顯示繁體中文。輸出欄位請見主教材的專題說明。
