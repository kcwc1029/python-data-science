# 範例輸出

本資料夾保存範例實際執行產物，均可重新產生：

- 第 19 節：lunch_report.csv。
- 第 20 節：scores_ 開頭的六份 CSV 與兩份 npy。
- 練習三解答（第 23 個程式）：commute_scenarios.csv。

成績表中的空白代表缺失或尚不可計算，不等於零。CSV 為 UTF-8 BOM，數值報表以兩位小數呈現；npy 保留計算精度。重跑各範例會覆寫自己的同名檔案。

驗證環境：NumPy 2.5.2、Pandas 3.0.5。23 份程式均以「警告視為錯誤」模式獨立執行通過，並在專案外的工作目錄驗證素材路徑。另檢查主教材 20 份內嵌程式與實體檔一致、Markdown 本地連結有效，以及成績的手算結果、同分排名、整科缺失、零變異、重複／空白學號、缺欄與空表處理。也已實際透過 uv run 執行第一份範例。
