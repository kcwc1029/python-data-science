## 練習一：月底餐費還能省多少

建議完成第 01–08、11、14–15 節後進行。

小安記錄了五天的早餐、午餐、晚餐，想知道每天有沒有超過 250 元，以及如果每天午餐省 20 元，這週能少花多少。請不要直接修改原紀錄，因為還要比較前後結果。

練習檔名：`numpy_src/練習01_月底餐費.py`。

```python
import numpy as np

# 列為五天，欄依序為早餐、午餐、晚餐，單位元。
costs = np.array([
    [50, 100, 120],
    [60, 90, 100],
    [40, 120, 150],
    [55, 110, 100],
    [50, 80, 90],
])
# TODO：先列出 shape，再逐題完成。
```

1. 印出 shape、ndim、size，口頭說明每一軸。
2. 求每天總額，以及五天中各餐別總額。
3. 找出每日費用「嚴格超過」250 的天數和日期編號（第一天編為 1）。
4. 建立獨立試算資料，午餐每天減少 20 元，其他不變。
5. 求整週原總額、新總額與省下金額，確認原資料沒變。
6. 討論：若某筆午餐只有 15 元，直接減 20 是否合理？先訂規則，再決定是否使用 clip。

驗收重點：每天總額 `[270,250,310,265,220]`；各餐別 `[255,500,560]`；超支的是第 1、3、4 天。原總額 1315、新總額 1215，省下 100。250 元那天不算超支。

解答：[21_解答_月底餐費.py](./numpy_src/21_解答_月底餐費.py)。

延伸提問：如果 250 是「平均每日預算」，而不是「每日上限」，超支的定義要如何改？本週平均每日 263，比平均預算多 13，和「有三天超過上限」回答的是不同問題。

## 練習二：三戶家庭一起團購

建議完成第 09–13、15 節後進行。

三戶家庭團購牛奶、雞蛋與吐司。各戶折扣只套商品金額，折扣後商品小計滿 500 元免運，否則該戶加收一次 60 元。題目假設分戶配送，不共用免運門檻。

練習檔名：`numpy_src/練習02_家庭團購.py`。

```python
import numpy as np

# 欄為牛奶、雞蛋、吐司。
prices = np.array([80, 60, 50])
# 列為三戶，各格是購買數量。
quantities = np.array([[2, 1, 1], [4, 2, 2], [1, 1, 3]])
# 三戶的折扣依序九折、原價、八折。
discounts = np.array([0.9, 1.0, 0.8])
# TODO：先寫出三個陣列的 shape，再決定折扣如何變形。
```

1. 計算各戶各商品原始小計。
2. 把 discounts 轉成 `(3,1)`，讓折扣按家庭套用。
3. 計算每戶折扣後商品總額。
4. 依折扣後商品總額計算每戶運費，再算應付金額。
5. 比較 `subtotals * discounts` 與 `subtotals * discounts[:, None]`；兩者都能執行，哪個才符合題目？
6. 新增第四戶 `[1,1,1]` 與九五折，重新執行，觀察錯誤寫法是否開始報錯。

驗收重點：原始商品總額 `[270,540,290]`；折扣後 `[243,540,232]`；運費 `[60,0,60]`；應付 `[303,540,292]`，全部共 1135 元。

解答：[22_解答_家庭團購.py](./numpy_src/22_解答_家庭團購.py)。

講師提醒：原題是方形的 `(3,3)`，很適合呈現「shape 相容，但意思錯了」。請學生用第一戶牛奶和雞蛋各手算一次，證明折扣是依家庭，而不是商品欄。

## 練習三：通勤月票值不值得

建議完成第 14–19 節後進行。此題全部票價與門檻均為自訂練習數字，不對應實際月票政策。

假設一張月票 1200 元；記錄十天交通費，其中一天漏記。希望估計二十個上班日的交通支出，再比較月票。已知零元那天是步行，所以不能視為缺失。

練習檔名：`numpy_src/練習03_通勤月票.py`。

```python
import numpy as np

# 每天來回交通費，NaN 是未記錄，0 是確實未花費。
fares = np.array([60, 60, 80, np.nan, 60, 0, 80, 60, 60, 80])
# TODO：先數有效資料，之後再算平均與情境估計。
```

1. 計算有效筆數、缺失筆數、已知總額。
2. 計算已知日平均、中位數、標準差，保留 0 元紀錄。
3. 以已知日平均估計二十天支出，和 1200 元比較。
4. 分別假設缺失那天為 0、60、120 元，用三份獨立情境重新估計十天平均與二十天總額。
5. 把情境名稱、補值假設、估計月支出與「估計支出減月票價」輸出至 `numpy_outputs/commute_scenarios.csv`。
6. 回答：只根據這十天，能否保證買月票一定划算？資料是否包含休假、其他交通工具，月票是否都能使用？

驗收重點：有效 9 天、缺失 1 天，已知總額 540 元、已知日平均 60。直接以有效日估計為 1200 元，僅在此假設下打平。三種補值情境估計月支出依序為 1080、1200、1320 元，差額為 -120、0、120。正差額表示月票在此情境較便宜。

解答：[23_解答_通勤月票.py](./numpy_src/23_解答_通勤月票.py)。

講師提醒：不要把估計寫成保證。這題用來練習在輸出數字旁邊同時說明假設，也讓學生看到「缺失值怎麼補」會改變判斷。

以 [20_成績統計與標準化.py](./numpy_src/20_成績統計與標準化.py) 為起點，另存 `numpy_src/練習04_成績分析變體.py`。修改資料請另存到 `numpy_datasets`，不要直接覆蓋原教材素材。
