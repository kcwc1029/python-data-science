# 長條圖教材輸出

所有數字均為虛構教學資料。搭配 [長條圖教材](../../長條圖_Bar_Plot.ipynb) 使用。

| 檔案 | 用途 |
|---|---|
| `18_雞蛋單價比較.png`、`.svg` | 每顆價格比較圖 |
| `18_雞蛋單價摘要.csv` | 保留盒價、顆數與每顆單價 |
| `28_分店每日平均.png` | 各店平假日的每日平均銷量 |
| `36_便當團購報告.png`、`.svg` | 團購份數與應收金額 |
| `36_各班應收摘要.csv` | 各班總份數、應收與平均每份金額 |
| `36_便當訂購核對明細.csv` | 各班各口味的份數、單價與金額 |
| `previews/` | Notebook 全部圖表預覽；contact_sheet.jpg 為總覽 |
| `verification.json` | 執行格數、圖數、範例數、版本與警告記錄 |

重跑存檔範例會更新同名檔案。Notebook 已嵌入圖形，可直接閱讀；維護者需要重建時請見 [工具說明](../../Data_Visualization_src/bar_plot_tools/README.md)。
