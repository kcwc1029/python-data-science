## 資料品質與使用範圍

- 06 是刻意含缺漏與待核對值的原始表；其餘檔案在題目宣告範圍內皆有值，不代表現實資料完整。
- 相同 x、y 不一定重複錯誤；04 每人編號不同，重疊是有效回答。
- 01、04、05 以不同人為觀測；02 以訂單為觀測；03、06 以物件為觀測；07、08 為同店跨時間紀錄，不能假設每列都是獨立受訪者。
- 滿意度為序位尺度，不能把 4 分理解成 2 分的兩倍滿意。
- 06 中 B11 尚未確認錯誤，B15 確認免費；不得把兩者直接當錯誤或缺漏刪除。
- 09 前晚便當未計前晚備料時間；自備費用未含工時，餐點份量與營養未控制。只用於條件篩選，不能宣稱全面公平的餐點比較。
- 10 為固定功率情境而非實測，不含電價。
