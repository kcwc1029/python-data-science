# 箱型圖資料字典

全部檔案為教學模擬資料，UTF-8 BOM編碼，無真實個資或市場行情。所有金額為新臺幣元，時間為分鐘；另有每100公克、每公斤單價的明確換算。代號是虛構識別，不能把相同金額當作重複事件。

除下述特殊檔案，其餘數值完整、皆可用。第06例刻意有空白、負數、待補文字；40分鐘為已確認的真實等待。第20例刻意有一列完全相同匯入，以及空白、負數、待補各一筆；25與18分鐘保留為有效觀察。

第10例是已彙總統計，一列一方案，原始明細不在教材中。其Q1、中位數、Q3、鬚與離群值按提供者的linear與1.5IQR說明讀取；n為提供者給定。不能用它重新計算合併樣本的分位數。

第15例為同一學員前後配對。第17例重量欄單位公克，售價欄為整包元數。第19例金額全為正數，刻意比較對數顯示與對數尺度重算。其他分組欄與識別欄完整。

## 01_九次午餐花費.csv

- 欄位：紀錄編號、金額。
- 列數：9（不含表頭）。
- 一列代表：小安一次一人份午餐的付款金額。
- 範圍、單位與樣本：九次已記錄午餐，單位元；不代表全體學員的花費。

## 02_八次通勤分鐘.csv

- 範圍、單位與樣本：八次單程通勤，單位分鐘，皆完整紀錄。
