# 資料字典

全部為虛構教學資料，亂數種子 20260923。目的為練習圖表與資料判讀，不代表市場行情、健康標準或真實店家表現。
CSV 使用 UTF-8 BOM，方便以試算表開啟。除 07 特意放入待清理值外，其餘為完整資料；19 為已彙總資料。金額均為新臺幣元。
連續數值以截斷常態、右偏亂數或整數抽樣產生，邊界截斷與四捨五入是教學設計，不能當作自然界分布模型。紀錄沒有真實身分資訊。
