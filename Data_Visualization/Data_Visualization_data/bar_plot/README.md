## 資料處理原則

- 09 檔案的奶茶空白代表未知，綠茶 0 是已確認零銷量；其餘 CSV 在題目指定的觀測範圍內完整。
- 日期為 YYYY-MM-DD 字串；本章先分組彙總，若需日期運算請轉 datetime。星期與日別是分類，順序請明確指定。
- 每一欄的計數、金額或時間皆為數值；類別、編號與日期皆是識別資訊，不可把編號當數量。
- 11 等候資料每人只觀測一次；12 消費資料則為同一人多次消費，不可視為十位獨立受訪者。
- 14 是單選、已加總次數；15 是複選，同一人可勾多項。兩者的百分比分母不能混用。
- 費用情境不含題目未列出的工時、品質與其他成本；圖表不能直接外推全民或全年。
