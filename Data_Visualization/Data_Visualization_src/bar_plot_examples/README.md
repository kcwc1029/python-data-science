# 長條圖獨立範例

搭配 [長條圖 Notebook](../../長條圖_Bar_Plot.ipynb)；每支範例已附設定，可獨立執行。保留整個 Data_Visualization 目錄。

從專案根目錄執行，例如：

```powershell
.venv/Scripts/python.exe "Data_Visualization/Data_Visualization_src/bar_plot_examples/01_第一張早餐銷量長條圖.py"
```

需要 numpy、pandas、matplotlib、seaborn 0.13.2 或以上。資料見 [欄位字典](../../Data_Visualization_data/bar_plot/README.md)，練習見 [工作單](./練習題.md)。
