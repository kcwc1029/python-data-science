# 折線圖獨立範例

搭配 [折線圖教材](../折線圖_Line_Plot.ipynb) 使用。每個檔案包含環境設定，可以獨立執行。

需要 pandas、matplotlib、seaborn；保留整個 Data_Visualization 目錄。從專案根目錄執行，例如：

```powershell
.venv/Scripts/python.exe "Data_Visualization/Data_Visualization_src/line_plot_examples/01_第一張飲料花費折線圖.py"
```

所有情境皆為虛構教學資料；14 份 CSV 的欄位與單位請見 [資料字典](../../Data_Visualization_data/line_plot/README.md)。
